# How To Ontology

How to Build an Ontology on top of the information from the Guideline.

## Development

- Potential Tools
  - RDF Libraries
    - RDF Editors
      - RDFLib
      - DotNetRDF
      - RDFSharp
      - SemWeb
      - Serializing RDF
      - Turtle
    - NoSQL triple stores for RDF
      - BrightstarDB
      - AllegroGraph
        - RDotNetRDF compatible
      - GraphDB
        - Commercial and free Version
        - Java based
    - Neo4J labs (Neosemantics ) enables the use of RDF in Neo4j
    - AWS Neptune is able to import RDF
      - Further testing on RDF in Neptune is needed!
  - SPARQL, the query language used to query data in semantic web technologies.
  - Web Ontology Language (OWL)
    - OwlDotNetApi
  - JSON-lD
  - Brick Schema
  - Schema.org
  - Jena (big Java Library incl. Triple Store)

## Research

- Interesting References
  - Commercial Tools to build RDFs
    - Protege
    - TopBraid Composer
- Information
  - RDF vs. OWL
  - RDF defines how to write stuff
  - OWL defines what to write → higher level to expression
  - OWL can be serialized in RDF
  - Turtle is a human readable form of RDF
